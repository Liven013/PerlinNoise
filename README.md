  В данном проекте на языке Golang реализована процедурная генерация шума Перлина. Этот алгоритм применяют при генерации различных ландшафтов, рельефов и текстур. 

  Алгоритм:
  Для создания шума на исходное изображение накладывается сетка, для каждого узла которой определяется случайный градиент. 
  
  ![vector_field](https://github.com/user-attachments/assets/dba9b0a4-ee0d-466d-891b-8a4177dcc041)
  
  Далее значение шума рассчитывается для внутренних точек. Для этого определяются векторы от 4 ближайших вершин сетки до точки, в которой рассчитывается шум, и вычисляются скалярные произведения векторов и соответствующих градиентов. 
  
  ![vector_field_with_nodes](https://github.com/user-attachments/assets/3235a281-dc66-4aeb-8095-2cd6bffef091)
  
  Итоговый результат значения шума получается интерполяцией полученных скалярных произведений.
  
  ![interpolation_example](https://github.com/user-attachments/assets/db03722a-5180-455d-ae34-89caf885bf74)
